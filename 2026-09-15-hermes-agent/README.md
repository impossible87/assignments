## 这是什么

Hermes Agent 是 Nous Research 开源的自主 agent（MIT 许可、自托管、Python）。这份作业不是"它很厉害"的介绍，而是一份**给完全没用过的人写的新手手册**：按六步路线图走完，你会得到一个装在自己机器或服务器上、能记住你、会自己长技能、可以从手机指挥的 agent。

页面覆盖：

- **新手路线图**（可勾选，进度存在浏览器里）：每一步都有命令和验收标准，没通过就不该往下走
- **安装**：Windows / macOS / Linux 三系统命令、平台支持分级（Tier 1 / Tier 2 / 不支持）、安装后目录布局、三个最常见的坑
- **配置模型**：三种初始化模式、13 家提供商的配置方法、配置优先级（CLI 参数 > config.yaml > .env > 默认值）
- **技能**：斜杠命令调用、一条消息最多叠加 5 个技能、怎么让它自己长出技能
- **记忆**（重点）：内置记忆的字符上限与写入规则、四类"记忆变死"的症状与解法、8 个外部记忆提供商、备份与恢复
- **MCP**：三步接入外部工具服务器、按服务器过滤工具、从 Claude Code 迁移
- **连接器**：一个 gateway 进程接入 Telegram / Discord / Slack / 飞书 / 企微 / 钉钉等
- **安全**：官方八层防护、危险命令审批的三种模式、三系统各自注意事项、容器隔离的加固参数

页面里有五个交互：新手路线图勾选（带进度记忆）、安装向导（选系统出命令）、模型提供商选择器、命令速查搜索、能力矩阵筛选。另有四张自绘 SVG 图解（架构分层、学习循环、配置优先级、安全八层）与一张发布节奏柱状图。

## 技术说明

- 单文件 HTML，无外部依赖：不请求任何 CDN、字体或图片，离线可用
- 图表（架构分层、学习循环、配置优先级、发布节奏）均为内联 SVG，由页面内数据数组驱动
- 交互为原生 JavaScript，无任何第三方库；新手路线图进度存在 localStorage
- 字体为内嵌子集（思源黑体 / 思源宋体 / Inter / JetBrains Mono，均为 OFL 开源许可）
- 响应式：手机、平板、桌面均可阅读；默认浅色，可切换深浅色与四种配色风格；支持打印导出 PDF

## 这是什么

把 17 款国内外主流大模型放进同一套坐标里比较：API 价格、第三方能力指数、响应速度与真实调用量。结论是能力最强的模型与最便宜的好模型之间差上百倍价格，而真实调用量最大的几乎都是便宜那一档 —— 所以选型的核心不是"谁最强"，而是"哪一档刚好够用"。

页面包含三张交互：**成本计算器**（改用量即时重算账单）、**选型向导**（按任务类型/预算/硬性条件筛出推荐，并给出排除理由）、**数据表排序筛选**（点表头排序、按厂商与开源状态筛选、关键词搜索）。
